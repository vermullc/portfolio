Database Development Project

Created a mock Access database for SwiftShip Deliveries with tables, queries, forms, reports, macros, and relationships; presented database functionality and data integrity concepts to class.

February 8, 2024 – April 12, 2024 Database Systems

Description

This project features a fully designed mock database solution created in Microsoft Access for a fictional company, SwiftShip Deliveries, as part of the Databases (ITEC 265) course. Working under the fictional consulting name Carter Consulting Company (CCC), I applied the Database Development Life Cycle (DDLC) to design and implement a prototype addressing SwiftShip's business challenge of tracking driver safety incidents. The database includes four interrelated tables: Drivers, Managers, Incidents, and Violations. These tables are structured with one-to-many relationships and supported by validation rules, input masks, and lookup fields to ensure data accuracy and integrity. The scenario-based approach simulates a professional consulting project, mirroring how a developer would plan and deliver a database tailored to client requirements.

The final Access database integrates queries, forms, reports, and macros to streamline data entry, analysis, and navigation. Single- and multi-table queries generate summaries for drivers, managers, and performance metrics, while reports such as Incidents by Violation Type visualize trends using charts and aggregated data. A two-level navigation form and custom macros create an intuitive interface for non-technical users, simplifying tasks such as adding records, closing objects, and exporting reports. The system demonstrates how effective relational design and interface planning can transform business processes into a functional and organized database solution.

Through this project, I strengthened my understanding of relational modeling, normalization, and Access development while improving my ability to present technical solutions in a professional setting. Presenting the database solution enhanced my confidence in explaining technical concepts clearly to non-technical audiences, a key skill in the IT field. The SwiftShip Deliveries project highlights my ability to combine database theory, design principles, and client-centered communication into a cohesive and practical deliverable.
