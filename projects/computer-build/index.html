Computer Build

Assembled a desktop PC from components, completed system wiring and Windows 11 installation, and later upgraded the hardware with additional memory, a new power supply, and a discrete graphics card.

October 16, 2023 – August 5, 2024 Hardware & Software

Description

This project features the assembly and configuration of a fully functional desktop PC created for the Hardware & Software (ITEC 233) course. The components for this build came from a preselected set of kits offered through a local vendor, and I chose the Intel Core i5 kit, which included the CPU, motherboard, RAM, storage drive, power supply, case, and Wi-Fi adapter. I began by reviewing the documentation for each component and preparing the motherboard for installation, including seating the CPU, mounting the stock cooler, installing RAM, and securing the NVMe SSD in the M.2 slot. After mounting the motherboard inside the case using standoffs, I connected the 24 pin ATX power connector, CPU power connector, SATA power and data cables, USB and audio headers, and all front panel connectors. Once everything was wired and secured, I completed the initial boot and verified BIOS detection for all components before installing Windows 11 from a USB drive.

Throughout the build process, I learned the importance of proper orientation, careful component handling, and thorough connector alignment to avoid bent pins, incomplete seating, or short circuits. Because this was my first time building a PC, gaining hands on experience was especially valuable and helped me connect the concepts we covered in class to the physical structure of a computer. After Windows installation, I completed driver updates, validated storage and memory recognition, and ensured stable operation. Working directly with real hardware strengthened my understanding of internal PC architecture and gave me practical confidence that goes beyond what can be learned through simulations or diagrams.

Nine months later, I returned to the system to complete two upgrades that would improve overall performance. I added a second matching 8 GB memory module to increase total RAM to 16 GB and installed a Radeon RX 6500 XT graphics card. Because the original 400 W power supply could not support a discrete GPU, I selected and installed a Corsair CX550M 80 Plus Bronze modular power supply after researching wattage requirements and compatibility. I then completed cable routing, installed the GPU into the PCIe x16 slot, connected the required power, and installed updated AMD drivers.

Through this project, I strengthened my skills in hardware assembly, component research, troubleshooting, and system configuration. Working with both the initial build and the later upgrades helped reinforce the value of careful planning, compatibility checking, and safe installation practices. The complete system reflects both my ability to follow precise build procedures and my confidence in expanding and upgrading a computer based on performance needs.
